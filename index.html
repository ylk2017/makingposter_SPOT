SPOT — Editable A0 Poster Generator

Create a one-slide, portrait A0 PowerPoint with editable text, shapes, arrows and captions. Original classroom evidence remains embedded as images.

Local image processing: uploaded evidence stays in this browser session. Internet access is required to load the pinned PptxGenJS library. There is no server-side processing or automatic session saving.

1. Poster details

Missing author details are exported as visible placeholders. Long titles or affiliations may require shortening.

2. Authentic classroom evidence

Use pre-cropped PNG or JPEG images, or adjust the crop controls below. Crop coordinates are percentages of the original image. Images are fitted proportionally, never stretched.

Keep the examples separate. Use the matched initial/revised pair from the before/after document. Do not substitute the unrelated first-attempt photograph from the chatbot example. Exclude the percentage infographic from the Error Detective crop.

Cropping only selects original image pixels. It does not reconstruct handwriting or improve resolution. Review each selected crop.

3. Editable captions

Keep captions concise. Export stops if the text-size estimate detects a likely overflow; body text is not silently reduced.
